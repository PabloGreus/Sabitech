<center>SABITECH</center>

> Aplicación web responsive para gestionar las reservas y la asistencia a las jornadas de charlas SABITECH, con control de asistencia mediante códigos QR temporales que se renuevan cada 30 segundos.

#### Conexion docker

- acceso por terminal al servidor
  docker exec -it ubuntu_apache bash
- ssh:
  ssh admin@localhost -p 2222
- conexion con la base de datos
  docker exec -it base_datos mysql -u root -p
